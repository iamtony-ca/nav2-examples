# reactive_round_robin_control
1. 이 노드는 이전에 실행했던 자식의 인덱스를 기억한다 (Stateful).

2. tick()이 호출될 때마다 단 하나의 자식만 실행한다.

3. 실행한 자식이 SUCCESS를 반환하면, 이 노드도 SUCCESS를 반환한다. (복구 액션 성공 -> 주행 로직 재시도).

4. 실행한 자식이 FAILURE를 반환하고, 그 자식이 마지막 자식이 아니면, 다음 자식을 실행한다. (중간 단계 복구 액션 실패 ->  다음 복구 액션을 실행).

5. 실행한 자식이 FAILURE를 반환하고, 그 자식이 마지막 자식이면, 이 노드는 FAILURE를 반환한다. (모든 옵션 소진 -> 최종 복구 실패).

6. 만약 한번 마지막 자식까지 실행됐지만, 또 틱이 실행되면 이 노드는 순환하여 다시 첫번째 자식부터 다시 시작한다.
